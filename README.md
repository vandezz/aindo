# Aindo - AI Chat

AI Chat to answer your tasks using OpenAI's GPT models.

## Features

- 🤖 Interactive chat interface with AI assistant
- 💬 Real-time conversation with context retention
- 🎨 Beautiful, responsive design
- 🔒 Secure - API keys stored locally in your browser
- ⚙️ Customizable model selection (GPT-3.5, GPT-4)

## Quick Start

1. **Clone or download this repository**

2. **Open the application**
   - Simply open `index.html` in your web browser
   - No installation or build process required!

3. **Configure your API key**
   - Click the settings button (⚙️) in the bottom right corner
   - Enter your OpenAI API key (get one at https://platform.openai.com/api-keys)
   - Select your preferred model
   - Click "Save Settings"

4. **Start chatting!**
   - Type your message in the input box
   - Press Enter or click the send button
   - The AI will respond to help you with your tasks

## Getting an OpenAI API Key

1. Visit https://platform.openai.com/signup
2. Create an account or sign in
3. Go to https://platform.openai.com/api-keys
4. Click "Create new secret key"
5. Copy the key and paste it in the Aindo settings

## Privacy & Security

- Your API key is stored only in your browser's local storage
- All communication goes directly from your browser to OpenAI
- No data is stored on any server
- You can clear your API key anytime from settings

## Requirements

- A modern web browser (Chrome, Firefox, Safari, Edge)
- An OpenAI API key
- Internet connection

## Usage Tips

- Use GPT-3.5 Turbo for faster, cost-effective responses
- Use GPT-4 for more complex tasks requiring deeper reasoning
- The AI maintains conversation context, so you can have multi-turn dialogues
- Press Shift+Enter to add a new line in your message
